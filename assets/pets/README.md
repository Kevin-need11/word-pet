# 🖼️ 寵物圖放這裡（Kevin 用 Nano Banana 生）

遊戲的寵物有 4 個進化階段。你只要把生好的圖，用**下面這 4 個檔名**放進這個資料夾，遊戲就會自動換上——**完全不用改任何程式**。圖檔還沒放進來時，遊戲會先用 emoji（🥚🦎🐲🐉）頂著，不會壞。

## 檔名對照（一定要用這 4 個名字）

| 檔名 | 階段 | 出現時機 | 目前暫用 emoji |
|------|------|----------|----------------|
| `egg.png`   | 蛋       | Lv.1 起  | 🥚 |
| `baby.png`  | 小龍寶寶 | Lv.3 起  | 🦎 |
| `teen.png`  | 小龍     | Lv.6 起  | 🐲 |
| `final.png` | 進化龍   | Lv.10 起 | ✨🐉 |

## 生圖建議（給 Nano Banana 的提示方向）

- **同一隻角色**的 4 個成長階段（蛋 → 幼體 → 少年 → 成體），造型要連貫、看得出是同一隻。
- **透明背景 PNG** 最佳（去背），這樣放在遊戲藍紫底上最好看。
- 正方形或接近正方形、正面、可愛童趣風，適合國小小孩。
- 尺寸建議 512×512 以上，遊戲會自動縮到合適大小。

## 換好之後

圖丟進這個資料夾 → 推上 GitHub（或跟阿凱說一聲，我幫你 push）→ 網站重新整理就看到新圖。

> 想多加寵物種類 / 更多進化階段？跟阿凱說，我調 `index.html` 裡的 `STAGES` 設定即可。
